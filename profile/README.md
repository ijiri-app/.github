## 이지리는

튜닝 정보는 카페 글, 인스타 댓글, 유튜브 설명란에 흩어져 있습니다.<br>
이지리는 **오너가 직접 태그한 부품**을 사진 위에 붙여, 보고 → 찾고 → 담는 흐름을 한 화면에 모읍니다.

<br>

<table>
  <tr>
    <td width="33%" valign="top">
      <h3>부품 태그</h3>
      사진 위 정확한 위치에 휠, 에어로, 하체, 파워트레인 부품을 태그합니다. 차종은 모델 · 세대 · 트림까지 구분합니다.
    </td>
    <td width="33%" valign="top">
      <h3>뒷면 탭</h3>
      폰 뒷면을 톡 치면 사진 위에 부품 캡슐이 떠오릅니다. 사진을 가리지 않고 볼 때만 꺼내 봅니다.
    </td>
    <td width="33%" valign="top">
      <h3>담기</h3>
      마음에 든 부품을 위시리스트에 담아 두고, 같은 부품을 쓴 다른 차를 이어서 찾아봅니다.
    </td>
  </tr>
</table>
